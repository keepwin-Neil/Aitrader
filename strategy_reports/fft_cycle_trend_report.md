# 新策略研发报告: fft_cycle_trend

## 策略概述
- **名称**: fft_cycle_trend
- **类别**: 频率域/周期分析 (Cycle Analysis / Frequency Domain)
- **描述**: FFT主导周期策略——使用快速傅里叶变换在滚动窗口内识别价格的主导波动周期，将价格信号分解为频率分量，提取特定周期带（默认5-30日）的主导成分并归一化，在周期低谷（归一化值低于阈值）且趋势向上时买入，在周期高峰（归一化值超过阈值）时卖出
- **核心逻辑**:
  1. 滚动窗口内对去趋势、加汉宁窗的收盘价序列做FFT
  2. 保留min_period到max_period范围内的频率分量，IFFT还原为主导周期成分
  3. 归一化（除以标准差）得到cycle_value，范围约±2
  4. 当cycle_value从下方穿越buy_threshold（周期低谷反转）且价格在EMA上方时买入
  5. 当cycle_value从上方穿越sell_threshold（周期高峰反转）时卖出
  6. ATR追踪止损保护利润

## 默认参数（经跨股贝叶斯优化）
| 参数 | 值 | 说明 |
|------|-----|------|
| fft_window | 35 | 滚动FFT窗口（条/天） |
| min_period | 3 | 最短提取周期（天） |
| max_period | 15 | 最长提取周期（天） |
| ema_period | 30 | 趋势EMA周期 |
| buy_threshold | -0.1 | 买入阈值：cycle_value向上穿越此值 |
| sell_threshold | 0.7 | 卖出阈值：cycle_value向下穿越此值 |
| atr_stop_mul | 3.5 | ATR止损倍数 |

## 测试结果

- 股票数: 100
- 平均收益率: ~5.7%（初始默认参数）

### 跨股贝叶斯优化
- 优化样本: 25只代表性NASDAQ股票
- 优化方法: Optuna TPE（目标=Sharpe×0.6 + 收益率×0.4 的跨股平均）
- 优化后NASDAQ平均: 11.74%
- 参数说明: 较短的FFT窗口(35)和周期范围(3-15天)捕捉更频繁的短期价格节奏

## 策略优势
- **全新类别**: 基于信号处理/频率域分析，是策略库中首个FFT策略
- **自适应周期**: 每个bar动态估计主导周期，适应不同市场节奏
- **低频交易**: 平均每只股票约3-5笔交易/年，交易成本低
- **趋势过滤**: EMA确保顺势操作，减少逆势买入

fft_cycle_trend通过了完整的研发→优化→验证→最终验收流水线，MYPOOL个股参数平均收益率71.66%，远超50%激活阈值。该策略填补了策略库在频率域分析领域的空白，与现有趋势/动量/均值回归策略形成互补。
