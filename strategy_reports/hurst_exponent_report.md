# 新策略研发报告: hurst_exponent

## 策略概述
- 名称: hurst_exponent
- 类别: 分形/混沌理论 (Fractal Analysis)
- 描述: 滚动Hurst指数判断市场状态，H>0.535趋势跟随+EMA确认，H<0.43均值回归+布林带，自适应切换
- 核心逻辑: 使用R/S (Rescaled Range) 方法计算滚动Hurst指数。H>0.5表示市场具有长期记忆(趋势持续性)，H<0.5表示均值回归倾向。策略根据Hurst值动态切换交易模式：趋势阶段用EMA交叉跟随，均值回归阶段用布林带反转。

## 默认参数（贝叶斯优化后）
| 参数 | 值 | 说明 |
|------|-----|------|
| hurst_window | 50 | R/S分析窗口 |
| hurst_trend | 0.535 | 趋势状态阈值 |
| hurst_mr | 0.43 | 均值回归状态阈值 |
| ema_fast | 20 | 快速EMA周期 |
| ema_slow | 40 | 慢速EMA周期 |
| bb_period | 30 | 布林带周期 |
| bb_std | 1.83 | 布林带标准差倍数 |
| rsi_period | 13 | RSI周期 |
| rsi_oversold | 38 | RSI超卖阈值 |
| rsi_overbought | 84 | RSI超买阈值 |
| atr_stop_mul | 2.36 | ATR止损倍数 |
