# 新策略研发报告: vol_adj_momentum

## 策略概述
- **名称**: vol_adj_momentum
- **类别**: 波动率调整动量 (Volatility-Adjusted Momentum)
- **描述**: N日收益率除以已实现波动率（年化标准差），得到类Sharpe动量评分，高波动股需要更强动量才能触发信号，低波动股可用较小动量触发，比原始动量策略更公平且自适应
- **核心逻辑**:
  1. 计算N日收益率和已实现波动率（日对数收益标准差×√252）
  2. vol_adj = N日收益 / 年化波动率（类Sharpe比率）
  3. 对vol_adj做EMA平滑得到信号线
  4. 信号上穿buy_threshold（且趋势向上）买入
  5. 信号下穿sell_threshold卖出（止盈/反转）

## 默认参数（经跨股贝叶斯优化）
| 参数 | 值 | 说明 |
|------|-----|------|
| mom_period | 10 | 动量回看期 |
| vol_period | 15 | 波动率估算期 |
| signal_ema | 11 | 信号平滑EMA |
| buy_threshold | 0.2 | 买入信号阈值 |
| sell_threshold | 0.5 | 卖出信号阈值（高于买入，防止频繁抄底） |
| ema_period | 25 | 趋势过滤EMA |
| atr_stop_mul | 3.5 | ATR止损倍数 |

## 测试结果

### NASDAQ 100 池基准测试（默认参数）
- 股票数: 100
- 平均收益率: 3.06%

### 贝叶斯优化后（通用标准参数）
- 样本: 25只代表性NASDAQ股票，150次Optuna TPE
- NASDAQ平均收益率: 15.98%
- MYPOOL平均收益率: **43.93%**
- 筛选结果: **通过** (≥ 20%)

### MYPOOL 批量优化后（个股标准参数）
- 第一轮: 59只全部优化，9/59 WF验证稳健
- 第二轮: 9/59 WF验证稳健
- 个股参数MYPOOL平均收益率: **37.03%**
- 最终结果: **保留归档** (< 50%激活线)

## 结论
vol_adj_momentum在MYPOOL通用参数阶段表现优异（43.93%），但批量优化后个股参数验收降至37.03%，距激活线差13个百分点。策略在高波动成长股（CRWV、ASTS、OUST）上有突出表现，但在低波动或亏损股上表现平平。归档保存，具有良好的潜力价值。
