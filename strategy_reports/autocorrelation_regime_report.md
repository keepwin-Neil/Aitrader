# 新策略研发报告: autocorrelation_regime

## 策略概述
- 名称: autocorrelation_regime
- 类别: 统计学 / 自相关机制切换 (Autocorrelation Regime Switching)
- 描述: 自相关机制切换 - 根据收益率自相关性在趋势跟踪和均值回归间动态切换
- 核心逻辑: 计算收益率的滚动自相关系数。正自相关(>阈值)表示趋势市场，策略切换为动量跟踪(EMA+ROC)；负自相关(<-阈值)表示均值回归市场，策略切换为逆向交易(RSI+BB)；中性区间不开新仓。

## 默认参数(优化后)
| 参数 | 值 | 说明 |
|------|-----|------|
| autocorr_lookback | 30 | 自相关计算窗口期 |
| autocorr_lag | 1 | 自相关滞后阶数 |
| regime_threshold | 0.1 | 机制判定阈值 |
| momentum_period | 25 | 趋势机制动量MA周期 |
| reversion_period | 20 | 均值回归BB周期 |
| rsi_period | 14 | RSI周期 |
| rsi_oversold | 25 | RSI超卖阈值 |
| rsi_overbought | 75 | RSI超买阈值 |
| atr_stop_mul | 1.5 | ATR止损倍数 |

## 结论
自相关机制切换策略是本批3个策略中表现最好的，在三个维度上都是最高: NASDAQ 9.13%, MYPOOL 13.24%。主要问题:
1. 自相关系数在短窗口(30天)内的估计噪声较大，机制判断不够稳定
2. 趋势/均值回归两套子策略各自信号条件偏严格，实际触发频率低
3. 中性机制(regime=0)占比过高时，策略处于空仓状态，错过行情
4. 均值回归子策略要求RSI<25同时Close<=BB下轨，在上涨市场中几乎不触发

该策略的核心思想 - 根据市场状态动态切换策略 - 具有很大潜力。建议:
- 使用更稳健的机制识别方法(如隐马尔可夫模型或波动率机制)
- 放宽均值回归子策略的入场条件
- 增加中性机制下的轻仓参与逻辑
