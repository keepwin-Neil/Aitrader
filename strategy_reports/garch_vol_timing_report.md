# 新策略研发报告: garch_vol_timing

## 策略概述
- 名称: garch_vol_timing
- 类别: GARCH波动率预测 / 波动率择时 (GARCH Volatility Timing)
- 描述: 用GARCH(1,1)递推公式预测条件波动率，计算当前波动率与基线的比率，低波动期顺EMA趋势入场，高波动期空仓
- 核心逻辑:
  - GARCH(1,1)递推: σ²_t = ω + α·r²_{t-1} + β·σ²_{t-1}，参数固定（可优化）
  - 年化条件波动率(%) = sqrt(σ²_t) × sqrt(252) × 100
  - 波动率比率 = 当前GARCH波动率 / rolling_mean(GARCH_vol, vol_ma)
  - 买入：EMA快线穿越EMA慢线向上（金叉）AND vol_ratio < vol_buy_thresh（低波动期）
  - 卖出：EMA死叉 OR vol_ratio > vol_sell_thresh（高波动期强制空仓）
  - ATR止损

## 最终参数（通用标准）
| 参数 | 值 | 说明 |
|------|-----|------|
| garch_omega | 0.00001 | GARCH ω 常数项 |
| garch_alpha | 0.05 | GARCH α ARCH效应系数 |
| garch_beta | 0.80 | GARCH β 持续性系数 (α+β=0.85<1, 稳态) |
| vol_ma | 20 | 波动率基线均值窗口 |
| vol_buy_thresh | 1.2 | 买入的最大波动率比率 |
| vol_sell_thresh | 1.9 | 触发空仓的波动率比率 |
| ema_fast | 5 | 快线EMA周期 |
| ema_slow | 20 | 慢线EMA周期 |
| atr_stop_mul | 3.5 | ATR止损倍数 |

## 测试结果

### NASDAQ 池基准测试（初始默认参数）
- 股票数: 100
- 平均收益率: -0.5%
- 最高: 58.9%
- 最低: -35.3%

### 贝叶斯优化后（通用标准参数）
- NASDAQ 平均收益率: 2.0%（优化提升+2.4%）
- MYPOOL定向优化: 46.9%

### MYPOOL 验证（通用标准参数）
- 平均收益率: 46.9%（n=59）
- 筛选结果: ✅ 通过（≥20%）

### MYPOOL 批量优化后（个股标准参数）
- 第一轮稳健升级: 10股 (10/177)
- 第二轮稳健升级: 10股 (同上)
- 最终MYPOOL平均收益: 15.0%（低于通用参数阶段）
- 最高: PL (136.8%)
- 最低: -12.1%
- 最终结果: 📦 保留归档（未达50%激活线）

## 结论
GARCH波动率择时策略在MYPOOL定向优化阶段表现出色（46.9%），但经过批量WF验证后，
个股标准参数的平均收益反而下降到15%，说明WF验证过程中大部分参数组合被判定为过拟合。
这反映出GARCH策略的参数高度敏感性：GARCH系数（α,β,ω）对不同波动率特征的股票差异很大。
建议：对高波动成长股（HOOD/APP/COIN等）单独优化GARCH参数，可能获得更稳定的WF表现。
