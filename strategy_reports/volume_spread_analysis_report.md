# 新策略研发报告: volume_spread_analysis

## 策略概述
- 名称: volume_spread_analysis
- 类别: 市场微观结构 / VSA (Volume Spread Analysis)
- 描述: VSA成交量价差分析 — 分析K线价差、收盘位置与成交量关系检测主力吸筹派发行为
- 核心逻辑: 基于Wyckoff方法论，通过分析三个维度检测主力行为：(1)价差比=当日振幅/平均振幅，(2)收盘位置=(Close-Low)/(High-Low)，(3)量比=Volume/AvgVolume。高量窄幅收高=吸筹，高量窄幅收低=派发，低量收高在下跌趋势中=供应枯竭。

## 默认参数（优化后）
| 参数 | 值 | 说明 |
|------|-----|------|
| vsa_lookback | 30 | 统计窗口期 |
| volume_high | 1.8 | 高成交量阈值(量比) |
| close_pos_buy | 0.6 | 买入收盘位置阈值 |
| close_pos_sell | 0.2 | 卖出收盘位置阈值 |

| trend_period | 25 | 趋势判断EMA周期 |
| atr_stop_mul | 3.0 | ATR止损倍数 |

## 结论
VSA成交量价差分析在理论上是一种优秀的主力行为检测方法，被Wyckoff学派广泛推崇。但在实际回测中表现不佳，主要原因：
1. VSA分析最适合分钟/小时级别数据，日线级别的价差和收盘位置信息丢失过多
2. 现代市场中算法交易占比高，传统"主力行为"模式的可辨识度降低
3. 吸筹/派发信号的确认需要较长时间，导致入场时机偏晚
4. 在成交量波动大的小盘股上，量比指标容易产生误判

建议在分钟级数据或结合盘口数据时重新尝试此方法。
