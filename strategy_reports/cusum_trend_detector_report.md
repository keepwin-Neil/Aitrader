# 新策略研发报告: cusum_trend_detector

## 策略概述
- 名称: cusum_trend_detector
- 类别: 统计过程控制 / 变点检测 (Statistical Process Control)
- 描述: CUSUM变点检测 — 使用统计过程控制理论检测趋势转变点，上升变点买入下降变点卖出
- 核心逻辑: 计算对数收益率的Z-Score，通过CUSUM(累积和)算法检测均值偏移。CUSUM+检测上升趋势变点，CUSUM-检测下降趋势变点。结合EMA趋势过滤和量比确认信号。

## 默认参数（优化后）
| 参数 | 值 | 说明 |
|------|-----|------|
| cusum_lookback | 20 | 滚动窗口计算收益率统计量 |
| cusum_threshold | 2.0 | CUSUM突破阈值 |
| cusum_drift | 0.2 | CUSUM漂移参数(允许范围) |
| trend_filter_period | 30 | 趋势过滤EMA周期 |
| vol_ratio_min | 0.5 | 最低量比要求 |
| atr_stop_mul | 1.5 | ATR止损倍数 |

## 结论
CUSUM变点检测是一种经典的统计过程控制方法，理论基础扎实。但在日线交易中存在以下问题：
1. CUSUM算法的串行计算特性（for循环）导致计算效率较低
2. 变点检测的灵敏度与误报率之间的权衡难以在所有股票上统一
3. 在高波动小盘股上，Z-Score噪声大导致频繁误触发
4. 需要更长的观察期才能累积有意义的CUSUM值，不适合快速反转市场

该策略更适合低波动大盘蓝筹股的中长期趋势跟踪场景。
