# 新策略研发报告: linreg_trend

## 策略概述
- **名称**: linreg_trend
- **类别**: 线性回归趋势质量过滤 (Regression-based Trend Quality)
- **描述**: 滚动OLS线性回归，通过R²（拟合优度）和斜率百分比衡量趋势质量，在高质量上升趋势中价格回调至回归中线以下后反弹时买入
- **核心逻辑**:
  1. 对近N根K线收盘价做OLS线性回归，得到斜率、截距、R²
  2. R² > r2_min 且 slope_pct > slope_min 定义为"优质趋势"
  3. 当优质趋势成立且价格从回归中线以下上穿时买入（回调后确认）
  4. 当斜率由正转负时卖出

## 默认参数（经跨股贝叶斯优化）
| 参数 | 值 | 说明 |
|------|-----|------|
| linreg_period | 20 | 线性回归窗口 |
| slope_min | 0.11 | 最小斜率（%/bar） |
| r2_min | 0.35 | 最小R²（趋势质量门槛） |
| band_std | 3.0 | 通道宽度（倍残差标准差） |
| ema_period | 30 | 辅助趋势EMA |
| rsi_max | 75 | 买入时RSI上限 |
| atr_stop_mul | 3.0 | ATR止损倍数 |

## 结论
linreg_trend通过了20%筛选，但最终MYPOOL个股参数验收仅达19.60%，未能激活。该策略在具有清晰线性趋势的股票（WDC、MU）上表现优秀，但对高波动震荡股（COIN、NBIS）效果欠佳。保留归档，待进一步优化或市场环境改变后复评。
