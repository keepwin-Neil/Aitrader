# 新策略研发报告: kaufman_efficiency

## 策略概述
- 名称: kaufman_efficiency
- 类别: 市场效率/自适应均线 (Market Efficiency)
- 描述: Kaufman效率比率(ER)识别强趋势(ER高=信噪比高)，结合ATR通道突破和成交量确认
- 核心逻辑: Kaufman效率比率 = 价格方向变化 / 总波动路径。ER接近1表示价格沿直线移动（强趋势），接近0表示震荡（无趋势）。策略在ER>0.2时识别为趋势状态，当价格突破KAMA+ATR通道且放量确认时买入。KAMA(Kaufman Adaptive Moving Average)根据ER动态调整平滑速度。

## 默认参数（贝叶斯优化后）
| 参数 | 值 | 说明 |
|------|-----|------|
| er_period | 18 | 效率比率回溯期 |
| er_threshold | 0.20 | 趋势确认ER阈值 |
| er_exit | 0.10 | 无趋势退出ER阈值 |
| kama_fast | 5 | KAMA快速常数 |
| kama_slow | 38 | KAMA慢速常数 |
| atr_period | 12 | ATR通道周期 |
| atr_mul | 1.62 | ATR通道倍数 |
| vol_period | 27 | 成交量均线周期 |
| vol_min | 0.54 | 最小成交量比率 |
| rsi_period | 14 | RSI周期 |
| rsi_sell | 73 | RSI卖出阈值 |
| atr_stop_mul | 2.36 | ATR止损倍数 |

- 两轮贝叶斯优化完成
- 平均收益率: 36.46%
- 最终结果: 保留归档 (<50%)

## 结论
Kaufman效率比率策略在识别强趋势方面有效，特别适合半导体周期股和高动量成长股。KAMA自适应均线提供了良好的趋势跟随效果。但36.46%的整体收益未达50%活跃门槛，主要因为：
1. RSI 73的卖出阈值偏紧，导致过早止盈
2. ER指标在震荡转趋势的过渡期存在信号延迟
3. 成交量过滤在部分小盘股上效果不佳

保留在策略仓库中，未来可考虑与其他策略组合使用。
